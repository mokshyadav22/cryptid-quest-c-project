# Cryptid Quest: The Terminal Labyrinth

A text-based roguelike RPG written entirely in the C programming language. This project was developed as an end-semester project for a 1st-year Bachelor of Engineering in Computer Science and Engineering curriculum.

## Features
- **Turn-Based Combat System:** Fight through a series of increasingly difficult dungeon monsters with dynamic health and attack scaling.
- **Inventory & Resource Management:** Manage health, gold, and restorative potions during your run.
- **Data Persistence:** Save and load game progress using C File Handling (`fopen`, `fprintf`, `fscanf`).
- **Modular Architecture:** Cleanly organized using custom structures, pointers, and user-defined functions.

## Syllabus Concepts Applied
This project integrates core 1st-semester C programming concepts:
- **Control Structures:** `switch-case`, `do-while`, and nested `if-else` loops for game flow.
- **Derived Data Types:** `struct` for player and monster profiles.
- **Pointers & Memory:** Passing references using pointers to update game states dynamically.
- **File I/O:** Reading and writing text files for game save slots.
